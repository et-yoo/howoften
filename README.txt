=====================================================
 How Often? 우리 반 설문 조사  —  설치 안내서 (선생님 개인 수업용)
=====================================================

■ 이게 뭐예요?
 6학년 영어 10단원 "How often do you ~?" 수업에서 쓰는 우리 반 설문 사이트예요.
 - 선생님은 TV(교실 컴퓨터)에서  주소/tv/  를 열고 "설문 방 만들기"를 눌러요.
 - 아이들은 휴대폰·태블릿으로 QR을 찍고 들어와요. (크롬북이 없어도 휴대폰 QR로 가능)
 - ① 질문 모으기 → ② 대답하기 → ③ 결과(TV에 막대그래프) 순서로 진행돼요.
 - 연습해 보고 싶으면 TV 첫 화면의 "가짜 학생 8명과 연습해 보기"를 누르세요. (설정 없이도 돼요)

 ※ 원래 사이트(often.13w.kr)를 만드신 분께 허락을 받은 개인 수업용 복제본이에요.
   다른 곳에 공개·배포하지 말아 주세요.

 ※ 원래 사이트는 서버 프로그램(socket.io)이 필요해서 GitHub Pages에 그대로 올릴 수 없어요.
   그래서 "실시간 연결" 부분만 구글 Firebase(무료)로 바꿔서 만들었어요.
   화면 모양·진행 방식은 최대한 비슷하게 맞췄지만 똑같은 코드는 아니에요.


■ 준비물
 1) 구글 계정 (Firebase 가입용 — 카드 등록 필요 없음, 무료 Spark 요금제)
 2) GitHub 계정 (이미 있으시죠! 이전 게임 올린 곳)


=====================================================
 1단계. Firebase 만들기 (처음 한 번만, 약 10분)
=====================================================
 1) 크롬에서  https://console.firebase.google.com  접속 → 구글 계정으로 로그인
 2) [프로젝트 만들기] (또는 "Firebase 프로젝트 추가") 클릭
    - 이름: 아무거나 (예: howoften-class)  → 계속
    - "Gemini"/"Google 애널리틱스" 사용 설정은 꺼도 돼요 → 프로젝트 만들기 → 완료될 때까지 기다리기

 3) ★ 먼저 데이터베이스부터 만들어요 (이 순서가 중요해요!)
    - 왼쪽 메뉴 [데이터베이스 및 스토리지] (예전 이름: 빌드/Build) → [Realtime Database] → [데이터베이스 만들기]
      (비슷한 이름의 Cloud Firestore 는 다른 거예요. 고르지 마세요!)
    - 위치: "싱가포르 (asia-southeast1)" 선택 (한국에서 제일 빨라요)
    - 보안 규칙: "잠금 모드로 시작" 선택 → 사용 설정

 4) 보안 규칙 붙여 넣기
    - Realtime Database 화면 위쪽 탭 [규칙(Rules)] 클릭
    - 안에 있는 글을 전부 지우고, 이 폴더의  firebase-rules.json  파일을 메모장으로 열어
      내용을 전부 복사해서 붙여 넣기 → [게시(Publish)] 클릭

 5) 웹 앱 등록하고 설정값 복사하기
    - 왼쪽 위 톱니바퀴 ⚙ → [프로젝트 설정] → 아래쪽 "내 앱"에서 웹 아이콘  </>  클릭
    - 앱 닉네임: 아무거나 (예: howoften) → "Firebase Hosting"은 체크하지 않고 [앱 등록]
    - 화면에  const firebaseConfig = { ... }  가 나와요. 그 안의 값들을 복사해 두세요.
      (apiKey, authDomain, databaseURL, projectId, appId 등)
    - ★ databaseURL 이 안 보이면 3단계(데이터베이스 만들기)를 먼저 안 한 거예요.
      데이터베이스를 만든 뒤 프로젝트 설정 화면을 새로 고침(F5) 하면 나와요.

 6) 이 폴더의  config.js  를 메모장으로 열어요.
    firebase: { ... } 안의 줄 앞 // 를 지우고 값을 붙여 넣어요. 예)

      firebase: {
        apiKey: "AIza.....",
        authDomain: "howoften-class.firebaseapp.com",
        databaseURL: "https://howoften-class-default-rtdb.asia-southeast1.firebasedatabase.app",
        projectId: "howoften-class",
        appId: "1:1234567890:web:abcdef"
      },

    ※ 따옴표 "" 와 쉼표 , 를 지우지 않게 조심하세요. 저장!
    ※ apiKey 가 공개돼도 괜찮아요. 안전은 4)번 보안 규칙이 지켜 줘요.


=====================================================
 2단계. GitHub Pages에 올리기 (낱말 놀이터 올릴 때와 똑같아요)
=====================================================
 1) GitHub 로그인 → 오른쪽 위 [+] → [New repository]
    - Repository name: howoften  (원하는 영문 이름)
    - Public 선택 → [Create repository]
 2) 새 저장소 화면에서 [uploading an existing file] 클릭
    - 이 폴더 안의 파일·폴더를 전부 끌어다 놓기
      (index.html, config.js, core.js, student.js, tv.js, style.css, favicon.svg,
       tv 폴더, lib 폴더, fonts 폴더)
      ★ 폴더 째로가 아니라 "안에 든 것들"을 올려요. index.html 이 맨 위(루트)에 있어야 해요.
      ※ README.txt, firebase-rules.json 은 올려도 안 올려도 상관없어요.
 3) 아래 [Commit changes] 클릭
 4) 저장소 [Settings] → 왼쪽 [Pages] → Source: "Deploy from a branch"
    → Branch: main / (root) → [Save]
 5) 1~2분 뒤 같은 화면 위에 주소가 나와요:  https://아이디.github.io/howoften/

    ● 아이들 화면 :  https://아이디.github.io/howoften/
    ● 선생님(TV) 화면 :  https://아이디.github.io/howoften/tv/     ← 끝에 /tv/ 꼭 붙이기


=====================================================
 3단계. 수업 전에 한 번 시험해 보기
=====================================================
 1) 교실 컴퓨터(또는 내 컴퓨터)에서  .../tv/  접속 → [설문 방 만들기 ▶]
    - 맨 위에 "Firebase 설정이 아직 없어요" 주황색 안내가 "없어야" 정상이에요.
 2) 화면에 QR과 4자리 방 번호가 나와요.
 3) 내 휴대폰으로 QR을 찍고(또는 아이들 주소로 들어가 방 번호 입력) 이름을 쓰고 들어가 보세요.
 4) 질문을 써서 보내면 TV에 노란 쪽지가 바로 떠요. → 되면 성공!

 ※ TV 화면 오른쪽 위 [📖 활동 방법]에 아이들에게 보여 줄 설명 슬라이드가 있어요.
   처음 쓰실 땐 [🎓 처음이세요? 튜토리얼]을 먼저 봐 주세요.


=====================================================
 수업 진행 순서 (선생님 화면)
=====================================================
 [설정]  학생 1명이 낼 질문 수, 설문에 넣을 질문 수, 대답 표현 힌트(없음/보기만/눌러서 넣기) 고르기
         → [설문 방 만들기]
 ① 질문 모으기 : 아이들이 질문을 써서 내면 노란 쪽지로 모여요.
         쪽지를 눌러 고르고(번호가 붙어요), ✎로 고치고, 🗑로 지울 수 있어요.
         [📚 교과서 질문] [+ 직접 쓰기] [모두 고르기] 버튼도 있어요.
 ② 대답하기 : 아이들이 고른 질문마다  I ( always ) eat vegetables.  처럼 괄호 안에 대답을 써요.
         누가 몇 개 했는지는 TV에 나오고, 늦게 온 아이도 QR로 들어와 대답할 수 있어요.
 ③ 결과 : 질문마다 막대그래프와 "가장 많은 대답"이 나와요.
         배운 표현이 아닌 대답은 [기타 의견]에 따로 모여요. 누가 썼는지는 아이들에게 안 보여요.

 · 아이가 잘못 들어왔으면 질문 모으기 화면에서 이름 칩을 눌러 "내보내기".
 · 수업이 끝나면 ⚙ → [방 닫기]. (안 닫아도 TV 화면을 끄고 6시간이 지나면 닫힌 방이 되고, 이틀 뒤 새 방을 만들 때 자동으로 지워져요.)
 · 아이가 같은 이름으로 다시 들어오면 쓰던 것이 그대로 이어져요.
   (같은 이름이 두 명이면 섞여요 → "7번 민수"처럼 번호를 같이 쓰게 해 주세요.)

=====================================================
 안 될 때
=====================================================
 ● "서버와 연결이 불안정해요" 가 계속 나와요
   → Firebase 1단계 4)번 규칙을 [게시] 했는지 확인. 규칙 탭에 firebase-rules.json 내용이 있어야 해요.
   → config.js 의 databaseURL 이 정확한지(https:// 로 시작, .firebasedatabase.app 또는
     .firebaseio.com 으로 끝남), 따옴표·쉼표가 빠지지 않았는지 확인.
 ● TV 첫 화면에 주황색 "Firebase 설정이 아직 없어요" 안내가 떠요
   → config.js 를 다시 올렸는지(GitHub에서 config.js 교체), 올린 뒤 1~2분 기다렸다가
     Ctrl+F5 로 새로 고침.
 ● GitHub에 새 파일을 올렸는데 화면이 그대로예요
   → 1~2분 기다린 뒤 Ctrl+F5. (휴대폰은 브라우저 새로 고침)
 ● 아이들 화면에서 "방 번호를 다시 확인해 주세요"
   → 4자리 방 번호가 맞는지, TV 방이 아직 열려 있는지 확인.


=====================================================
 알아 두면 좋은 것
=====================================================
 · 무료(Spark) 요금제 한도: 동시에 접속 100명, 저장 1GB. 한 반(약 30명)은 넉넉해요.
 · 아이들 이름·대답은 Firebase에 저장되지만 이틀 지나면 방과 함께 지워져요.
   (이름 칸에는 번호나 별명만 쓰게 해 주세요.)
 · 방 번호(4자리)만 알면 누구나 그 방에 들어갈 수 있어요. 교실 수업용으로는 충분하지만
   방 번호를 학교 밖에 공유하지는 마세요.
 · 원래 사이트의 통계(분석) 스크립트는 넣지 않았어요.
 · 이 사이트는 화면 키보드를 직접 만들어 넣었어요. 컴퓨터 키보드로도 칠 수 있어요.
